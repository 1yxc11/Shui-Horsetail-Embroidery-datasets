# Annotation Files

This directory contains manually traced vector annotations for the Shui Horsetail Embroidery dataset.

## Structure

| Directory | Description |
| :--- | :--- |
| `vector_1000/` | Complete set of 1,000 SVG annotations. Filenames correspond to the raster images in `../images/`, e.g., `001.svg` matches `../images/001.png`. |
| `vector/` | Original representative annotation examples retained for reference. |
| `rawdata/` | Raster images corresponding to the representative examples. |

All SVG files were traced with semantic guide paths for the VP-SHE workflow.
